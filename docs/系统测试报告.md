## 一、测试概述

### 1.1 测试目的
验证系统各功能模块是否满足需求规格，重点覆盖：

1. 数据可视化类页面的取数与图表渲染是否正常；
2. 用户管理与操作日志的增删改查是否正确、可审计；
3. 三级权限模型（公开 / 需登录 / 仅管理员）是否严格生效；
4. 后端输入校验与异常处理是否健壮。

| 前端 | 纯 HTML5 + CSS3 + 原生 JS + Apache ECharts |
| 浏览器 | Chrome / Edge（1400~1920px 视口） |
| 测试数据 | 仓库 12213 条、组织 2067 个、快照日期 2026-08-11 |

## 四、缺陷记录

| 编号 | 严重程度 | 描述 | 状态 |
|---|---|---|---|
| DEF-01 | 轻微 | CSV 导出响应头 `Content-Type` 出现 `charset=utf-8` 重复（Werkzeug 对 `text/*` 自动追加 + 代码手工追加所致） | ✅ 已修复（`mimetype="text/csv"`），需重启生效 |

## 五、测试结论

1. 系统 **33 个测试用例全部通过**，通过率 100%，无阻断性缺陷。
2. **三级权限模型**（公开 / 需登录 / 仅管理员）严格生效，401/403 拦截符合预期，普通用户无法越权访问管理接口。
3. **用户管理全程可审计**：增、删、改、登录、导出、改密等操作均写入 `sys_log`，日志字段（时间/用户/操作/详情/IP）完整。
4. 后端对**非法角色、重名、自删、自降级、弱密码、错误原密码**等异常输入均做了校验与拦截，健壮性良好。
5. 遗留 1 项优化建议（服务端分页），不影响当前系统功能与论文演示。
